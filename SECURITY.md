# Security policy

The latest tagged release is supported. No independent security audit is claimed.

Use [private vulnerability reporting](https://github.com/haoyuanxue26-star/wheelwatch/security/advisories/new)
for parser crashes, resource-limit bypasses or integrity-check bypasses. Include
Python version, platform, selected limits and a minimal generated fixture. Do not
upload private packages or live malware. If private reporting is unavailable,
open an issue requesting a private contact without disclosing exploit details.
No response-time SLA is guaranteed.

A malicious wheel with recomputed RECORD hashes is outside the integrity threat
model. Heuristic risk warnings are explicitly not comprehensive malware detection.
